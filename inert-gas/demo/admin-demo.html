Visitors per day

Anonymous daily count for the last 14 days. Each browser is counted once per day with a scrambled code that changes daily, so nobody can be followed across days.

Review queue

Approve, hold or delete what people send in.

Messages

Private messages from visitors. Only you can see them. Moderators have no access.

Filters

Choose what gets held for review. Held writing goes to the Review queue. A filter never deletes or publishes anything.

Try a sentence

See whether a sentence would be held. This uses the edits on screen, even before you save.

Always allowed

Phrases that must never cause a hold. They are ignored before the rules run, so "minor in physics" is not caught by the word "minor". One per line.

Urgent words in private messages

A message to you containing one of these is marked urgent and the writer sees the support lines. One per line. End with * to match word endings. Leave empty for the built-in list.

Poll of the day

Run one poll at a time. Starting a new one closes the current poll.

New poll

A question and two to four options.

Current poll

Settings

Wall behaviour and public text.

Announcement banner

Shown at the top of the wall. Leave empty to hide.

Timing and limits

Posts go live after a random delay so nobody can be linked to their post by timing.

Support lines

Shown in the rules, when a post mentions self-harm, and in the message window. One per line as Name | number | note. The number becomes a call link. A line without " | " stays plain text. Only add numbers you have verified.

Weekly theme and prompt

Shown as a card above the wall, and in the composer with a button that fills in the prompt. Leave both empty to hide it.

Message flood protection

There is no limit on how many messages you can receive. If one network address sends too many messages too fast, it is flagged and blocked until you deflag it under Messages, Flagged. Deflagging resets its count to zero. The address is logged with every message.

Moderator applications

Shows an Apply button under the poll of the day. Applicants give their real identity, answer private questions and upload their college ID. Only you can see applications, under Team. The ID photo is deleted when you decide.

Moderator page address

Moderators sign in at yoursite/. Letters, numbers and dashes only.

Confession of the day

Moderators and data

Give trusted people review access, and back up the wall.

Moderator applications

Real names, details and ID photos. Only you can see this. Deciding deletes the ID photo.

Moderators

Moderators can review held items but cannot approve anything about self-harm, minors, doxxing, threats, accusations or sexual content.

Export

Download every confession and comment, including held and deleted ones.

Mod chat

Announce to every moderator, chat with them informally, or message one privately. Moderators cannot message each other privately, and they never see who has read what. Only you do.

Content

Edit every piece of public text: rules, prompts, report reasons, the privacy policy, the announcement, all labels and messages, and the moderator application. Changes show on the wall the next time someone loads it.

Schedule

Choose when the site goes dark by itself. While it is down, visitors see the browser's own "This site can't be reached" page, as if the website never existed. You can always open your admin address.
